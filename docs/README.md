# 📚 Temarios completos de ActuarIQ

Un documento por materia con **todo el contenido de cada módulo**: preguntas, respuestas,
procedimientos, explicaciones y las fórmulas clave, organizado **por parcial**.

Se generan recorriendo los generadores reales de cada materia dentro de la app, así que se
mantienen fieles al contenido del curso. Las preguntas numéricas muestran valores de ejemplo;
el método y la respuesta son los del generador del curso.

## Nota sobre los parciales

La división por parciales de **Procesos Estocásticos** es la real (según los apuntes).
En las demás materias se marca como **división sugerida**: ajústala con tu profesor si
cambia. Todo esto se controla en un solo lugar del código (`SUBJECT_PARCIALES`), por si
quieres que la cambie.
